# Changelog

## 1.1.0

- Исправлены численно зависимые подписи: при 1, 2, 5, 11, 21, 22 и 25 они
  больше не дают неверных русских падежей. Исправлены cron-фразы, действие
  сброса и несколько терминологических расхождений.
- Добавлен отдельный русский словарь для 63 ключей `dsh-session-manager` 0.5.0
  через публичный API локализации DSH; файлы стороннего плагина не меняются.
- Проверка совместимости читает версию из установленного `app.asar`, сравнивает
  английский каталог с реальной сборкой и падает при отсутствии пути/версии.
- Линтер игнорирует разделители при проверке кириллицы, сохраняя проверку
  пользовательского текста. Добавлены регрессионные тесты для найденных дефектов.
- Отчёт разделяет 2888 ключей ядра, 63 ключа Session Manager и метаданные
  пакетов. Подмена метаданных чужих пакетов не реализована: DSH 0.2.1-rc.2
  читает их из локальных файлов самих пакетов и не предлагает публичный API
  для внешних переводов.
- Исправлен путь к манифесту в хостовом модуле.

## 1.0.0

Первый публичный выпуск.

- Русский язык (`ru`) зарегистрирован через публичный API
  `ctx.locale.addLanguage` с fallback на `en`; он появляется в стандартном
  списке **Настройки → Общие → Язык** как «Русский».
- Переведены все 62 пространства имён каталога DSH — 2888 из 2888 английских
  ключей (100 %), включая ARIA-подписи, разделители и варианты `.one`/`.other`.
- Словари регистрируются отдельными `ctx.effect`, поэтому выгрузка плагина
  снимает и язык, и все словари.
- Добавлены инструменты сопровождения: `snapshot` (снятие каталога из
  установленного DSH), `sync` (пропущенные / устаревшие / изменённые ключи),
  `check` (линт словарей), `report` (отчёт о покрытии), `package` (сборка
  устанавливаемого архива).
- Добавлен набор из 45 тестов: целостность словарей, плейсхолдеры, контракт
  бандла, совместимость с установленным Harness, поведение детектора дрейфа.
- Исходные файлы DeepSeek Harness не изменяются; подмена текста через DOM не
  используется.
