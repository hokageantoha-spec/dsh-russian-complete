# dsh-russian-complete

Русификатор **DeepSeek Harness Desktop**. Добавляет язык **«Русский»** через
публичный API локализации. Проверен на Windows с **DSH 0.2.1-rc.2** и
**Session Manager 0.5.0**. Независимый проект сообщества.

## Скачать

**[Релиз 1.1.0 — установочный архив и исходники](https://github.com/hokageantoha-spec/dsh-russian-complete/releases/tag/v1.1.0)**

В разделе Assets:

- `dsh-russian-complete-1.1.0.tgz` — готовый плагин для установки;
- `dsh-russian-complete-1.1.0.tgz.sha256` — контрольная сумма;

- `dsh-russian-complete-1.1.0-source.zip.sha256` — контрольная сумма исходников.

## Что переведено

| Источник строк | Покрытие |
| --- | --- |
| Словари ядра DSH | 2888 / 2888 ключей в 62 пространствах имён |
| Session Manager 0.5.0 | 63 / 63 ключа, отдельное пространство имён |
| Названия и описания пакетов | Отдельный хостовый канал, вне клиентского API |

100% ключей словарей **не означает полного перевода всего интерфейса**.
Английские названия `Agent Teams`, `Voice input`, `Developer Tools` и
нативное меню остаются ограничениями API текущей версии DSH.

Плагин регистрирует язык через `ctx.locale.addLanguage` и словари через
`ctx.locale.register`. Файлы DSH и стороннего Session Manager не меняются;
подмена DOM и сетевые запросы в русификаторе не используются.

## Что изменилось в 1.1.0

- Исправлены числовые шаблоны для 1, 2, 5, 11, 21, 22 и 25.
- Добавлен перевод всех 63 ключей Session Manager через публичный API.
- Исправлена проверка совместимости с фактически установленной версией DSH.
- Устранены ложные предупреждения о разделителях и ошибка пути к манифесту.
- Покрытие ядра, внешнего словаря и метаданных подсчитывается отдельно.

Пройдены **63 теста** и **14 проверок архива**. Клиентский код публичного
пакета побайтово совпадает с проверенной установленной версией.
Реально проверены настройки, Session Manager и переключение языков.

В пустом Session Manager есть косметическое повторение заголовка
«Архивные сессии». Другие версии DSH и Session Manager требуют отдельной
проверки совместимости.

Подробности: [CHANGELOG.md](CHANGELOG.md). Полные отчёты покрытия и выпуска
находятся в архиве исходников.

Ошибки перевода и предложения:
[Issues](https://github.com/hokageantoha-spec/dsh-russian-complete/issues).
Укажите версию DSH, экран, текст и ожидаемый перевод.
